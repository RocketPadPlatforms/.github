# Security Policy

This policy applies to all public repositories of RocketPadPlatforms that do not
have a security policy of their own.

## Supported Versions

Only the latest release of each project receives security fixes. Please check
that the issue is still present in the latest release before reporting it.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues, pull
requests or discussions.

Report them privately through GitHub instead:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab.
3. Click **Report a vulnerability**.

Please include:

- the affected repository and version (release tag or commit)
- a description of the issue and its impact
- steps to reproduce it, or a proof of concept
- any suggested fix or mitigation

## What to Expect

We acknowledge reports within 7 days, on a best-effort basis. We keep you
updated while we work on a fix and publish a security advisory once it is
released. Let us know if you would like to be credited.

## Third-Party Components

Vulnerabilities in upstream projects that our repositories use or vendor (for
example Talos Linux, Kubernetes, Cilium or third-party Helm charts and
manifests) should be reported to those projects directly. Let us know if a
release of ours needs an update in response.
